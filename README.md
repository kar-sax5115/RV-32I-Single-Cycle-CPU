# RV-32I-Single-Cycle-CPU
Single-cycle 32-bit RISC-V (RV32I) CPU in Verilog. Supports R/I-type ALU ops, byte/half/word loads and stores, all six branches, JAL/JALR, LUI and AUIPC. Features a single shared adder/subtractor and shifter in the ALU, a 4 KB data memory, and a modular datapath. Built and simulated in Xilinx Vivado.
